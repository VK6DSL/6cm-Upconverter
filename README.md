# 6cm-Upconverter
Amateur Radio 6cm (5.7GHz) upconverter project by VK6DSL - Western Australia

## Overview
- 6cm Upconverter using Mitec 9020 Satellite Up Coverter as the Foundation

## Hardware
- Mitec 9020 Satellite Earth Station Up Converter with Option 22 (140 Mhz Input IF.
- Kuhne MKU LO 8 - 13 PLL 2 (Oscillator)
- Codan 5740 40W SSPA

## Frequency Plan
- Full 6cm Amateur Band 5650 to 5850 output capability
- IF Input 144 Mhz
